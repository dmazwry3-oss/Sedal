ROUTING

AUTO — try the Netlify proxy first, fall back to a direct browser call.

PROXY — always use the serverless function (/api/proxy). No CORS issues. Requires Netlify deploy.

DIRECT — call the API straight from your browser. Fast, but may be blocked by CORS.

DEPLOY

Push to GitHub → import the repo on Netlify. The included netlify.toml + netlify/functions/proxy.js wire everything up automatically — no build step.

MOBILE

Tap ⤓ INSTALL (or your browser's "Add to Home Screen") to run XEMOZ fullscreen like a native app — it even works offline.

Once installed you can share a link straight from Instagram / TikTok / X into XEMOZ via the system share sheet.

Tap ✦ FX to toggle lite mode (disables the matrix rain) to save battery on older phones.
